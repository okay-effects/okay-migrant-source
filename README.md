# okay-migrant

A legal assistant for an immigrant. A country's rules for foreigners are read from its official texts into exact
models (the method: [okay-study]); the assistant asks for the facts a case lacks and answers with the rule's
source and its date. Information, not legal advice.

First topic: the CUKR residence card in Poland (`books/pl/cukr/`, the Office for Foreigners' materials).
